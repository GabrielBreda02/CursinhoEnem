# Sistema-Web-de-Banco-de-Quest-es-e-Composi-o-de-Provas
Sistema web desenvolvido com HTML, CSS e JavaScript, integrando uma API REST para gerenciamento de banco de questões e composição de provas acadêmicas, permitindo cadastro, edição, exclusão e filtragem de dados por área, disciplina e professor.
Aplicação web desenvolvida com HTML, CSS e JavaScript, com consumo de uma API REST, voltada à criação e gerenciamento de provas acadêmicas.

O sistema permite o cadastro de professores, disciplinas e áreas, criação e manutenção de um banco de questões, além da composição dinâmica de múltiplas provas, onde o professor pode selecionar, editar ou excluir questões conforme sua disciplina.

Inclui funcionalidades de CRUD completo, filtros de dados, organização por contexto acadêmico e geração de provas com base nas escolhas do usuário, simulando um ambiente real de gestão educacional.

## Funcionalidades
- Cadastro de professores, disciplinas e áreas
- CRUD completo de questões
- Criação, edição e exclusão de provas
- Filtros por área, disciplina e professor
- Composição dinâmica de provas
- Consumo de API REST
- Interface desenvolvida sem frameworks
